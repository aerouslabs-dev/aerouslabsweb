# AGENTS.md

Architecture notes for AI agents (and humans) working on this codebase.

## Overview

Aerous Labs is a TanStack Start (React 19 + TanStack Router, SSR) application deployed on Netlify. It is a single marketing page assembled from section components, plus an `/admin` control panel. All editable content lives in Netlify Database (Postgres via Drizzle); uploaded app icons live in Netlify Blobs.

## Directory structure

```
db/
  schema.ts        # Drizzle table definitions (apps, tools, app_tool_allocations, roadmap_items, site_settings, feedback)
  index.ts         # Drizzle client (netlify-db adapter, zero-config)
netlify/
  database/migrations/   # Generated by drizzle-kit — never hand-edit, never skip after a schema change
  functions/image.ts      # Serves uploaded app icons from Netlify Blobs at /api/image/:key
src/
  server/
    data.server.ts        # All DB reads/writes + admin auth token verification + weighted matrix calculation
    image.server.ts        # Blob store read/write/delete helpers
    aerous.functions.ts     # createServerFn wrappers — the only server code callable from client components
  components/site/         # Presentational sections (Hero, Navbar, AppsShowcase, TransparencyMatrix, Roadmap, ContactSection, Toast, Logo, TerminalWindow, NodeNetwork, TiltCard)
  lib/types.ts             # Shared TypeScript types + enums (APP_STATUSES, APP_NATURES, ROADMAP_STATUSES) mirrored on client and server
  routes/
    index.tsx    # Public landing page — loads data server-side, then polls getPublicData() every 6s for near-live updates
    admin.tsx     # Login gate + full CRUD dashboard (single file by design — it's a set of tabbed forms, not a design system)
    __root.tsx    # Document shell, favicon links, global meta
  styles.css      # Tailwind v4 theme (CSS custom properties drive the shadcn-style tokens), obsidian/cyan/emerald palette, glass/gradient/animation utilities
```

## Conventions & non-obvious decisions

- **No content-collections / markdown.** The scaffolded portfolio template's blog/jobs/education content system was removed entirely — this site has no blog. Don't reintroduce it for unrelated features.
- **Admin auth is intentionally lightweight.** `adminLogin` checks a hardcoded username/password (see `data.server.ts`) and returns an HMAC token derived from a server-side secret. The client stores that token in `localStorage` and passes it back on every admin mutation; `isValidAdminToken` recomputes the same HMAC to verify it. There is no session table — this is a single shared studio credential, not per-user auth. If real user accounts are ever needed, use Netlify Identity instead of extending this.
- **"Live" updates are polling, not websockets.** The public page calls `getPublicData()` on a `setInterval` (6s) so admin edits appear without a manual refresh. This is a deliberate simplicity tradeoff; if true push updates are needed, introduce a proper realtime channel rather than shortening the poll interval further.
- **Weighted transparency matrix** is computed in `getTransparencyMatrix()` as a plain average of each tool's percentage across *all* apps (apps with no allocation for a tool count as 0%). That is the "weighted average" the spec asked for, with equal weight per app.
- **Images are Netlify Blobs, not the database.** `imageKey` on an `apps` row is a blob key; the actual bytes are never stored in Postgres. The Netlify Function at `netlify/functions/image.ts` is the only reader of that blob store outside of `image.server.ts`.
- **Schema changes require a migration.** Any edit to `db/schema.ts` needs a corresponding `npx drizzle-kit generate --name <...>` run so a SQL file lands in `netlify/database/migrations/`. Without it the deployed database schema will not change.
- **Logo is inline SVG, not a raster asset.** The hexagon mark is defined twice — `Logo`/`LogoMark` in `src/components/site/Logo.tsx` for in-app use, and `public/favicon.svg` / `public/apple-touch-icon.svg` for browser chrome. Keep the gradient stops (`#00F2FE` → `#10B981`) and hexagon geometry in sync if either is edited.
